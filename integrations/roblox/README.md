# Argila → Roblox Studio

1. In Argila, open **Engines → Roblox Studio**, choose an export folder, and set the format to `obj` or `glb`.
2. Click **Enviar cena** (send scene) or **Enviar seleção** (send selection).
3. In Roblox Studio, go to **Home › Import 3D**, select the exported file, and confirm.

Notes:
- Roblox limits each mesh to about 20k triangles. Use **Modificadores › Decimar** in Argila to reduce the count if needed.
- Colors and textures come along with the GLB. OBJ carries only the geometry.
